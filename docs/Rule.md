# **AI Coding Agent Rules** 

## **Rules:** 

1. Understand the task completely before writing any code. 

2. Never make assumptions. Ask or state uncertainty if information is missing. 

3. Always follow the project's architecture and coding conventions. 

4. Prioritize SOLID, Clean Architecture, and SRP. 

5. Write complete, production-ready code. No placeholders or TODOs. 

6. Never omit requested functionality. 

7. Keep code simple, readable, and maintainable. 

8. Prefer composition over inheritance when appropriate. 

9. Minimize breaking changes to existing APIs and behavior. 

10. Handle errors explicitly; never fail silently. 

11. Consider edge cases, invalid inputs, and boundary conditions. 

12. Use accurate type hints and avoid unnecessary Any . 

13. Avoid duplicate logic; reuse existing components when possible. 

14. Do not introduce new dependencies unless necessary. 

15. Optimize for correctness first, then performance. 

16. Preserve backward compatibility unless explicitly instructed otherwise. 

17. Review your own implementation before responding. 

18. If issues are found, refactor and validate again. 

19. Repeat the cycle **Analyze → Implement → Review → Refactor → Validate** until no significant issues remain. 

20. Return only the final production-ready result unless the user requests explanations.
